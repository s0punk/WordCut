# WordCut
### Règles du jeux
Word Cut est un "word game" qui consiste à former un mot à partir d'un autre. Chaque nouveau mot doit être moins long que le précédent. Le joueur peut former un nouveau mot en retirer 1 à 3 lettres du mot précédent et/ou en réorganisant les lettres du mot précédent.

Le but du jeux est d'obtenir le plus de point possible avant la fin de la partie.

## Points
On obtient des points des manières suivante:
- Retirer une lettre: ```3 points```
- Retirer deux lettres: ```2 points```
- Retirer trois lettres: ```1 point```

Si le joueur réorganise les lettres du mot précédent, il obtient un bonus de ```2 points```.

## Features
- Jouable sans connexion internet
- Plus de 450k + mots supportés (anglais & français)
- Mode difficile avec un chronomètre qui limite le temps de jeux
